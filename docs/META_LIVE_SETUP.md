# Подготовка Open-autoDM к режиму Live в Meta

Приложение Meta: `1833305417690234`, Open-autoDM. Сервис: `https://autodm.niar42.com`.

6 октября 2026 Meta возвращает 1885183 при validate_only новых рекламных креативов Snippist из двух существующих постов. В Publish приложение остаётся Unpublished; кнопка отключена и указан недостающий Privacy policy URL. Переключение режима не подтверждает рекламные привязки всех Instagram и не заменяет App Review / Advanced Access, если они потребуются для конкретных разрешений.

## Подготовленные страницы

- `/privacy` — оператор, виды данных, цели, Meta/Supabase/внешние боты, защита, сроки и запросы на удаление.
- `/data-deletion` — ручной запрос оператору, проверка запроса, отзыв Meta-доступа и пределы удаления.
- Контакт: публичный Telegram `https://t.me/niarkh`, указанный на сайте оператора `https://niar42.com/`.
- Обработка через внешних ботов описана условно: выбор AI-провайдера находится у бота.
- Сроки проверены по существующим SQL cleanup-функциям. Универсального автоматического удаления всех данных или удалённого контента страницы не обещают.
- Управляющая панель и API сохраняют существующую авторизацию `APP_OWNER_EMAILS` и ключи владельца. Новые страницы доступны без входа.

Публичные страницы опубликованы по адресам `https://autodm.niar42.com/privacy` и `https://autodm.niar42.com/data-deletion`.

## Выпуск после подтверждения

1. Проверить текст и визуальный вид обеих страниц. Получить подтверждение публикации текста, включая публичный контакт оператора.
2. Собрать и развернуть эту версию поверх текущего production, сохранив runtime secrets и работающий worker. Проверить публичные страницы без авторизации, health, запрет доступа к управляющему API без ключа и текущие подключения.
3. В Meta App settings → Basic сохранить Privacy policy URL `https://autodm.niar42.com/privacy` и User data deletion → Data deletion instructions URL `https://autodm.niar42.com/data-deletion`.
4. Прочитать актуальные требования Publish. Перед окончательным переходом в Live получить подтверждение конкретного изменения режима приложения. Если Meta добавит условия или запросит новые права, обработать их отдельно.
5. Проверить видимый Published/Live статус, сохранить подтверждение и повторить Meta validate_only креативов. Проверить сохранённые подключения/токены; платную рекламу не запускать.

Проверено локально: TypeScript, production-сборка, визуальный просмотр обеих страниц и переходы между ними; анонимные `/privacy` и `/data-deletion` возвращают 200, управляющий `/api/v1/ads/accounts` без ключа — 401. На сервере подтверждён один разрешённый владелец. Текущая база развёртывания — `440ad87ae45d57ccc7f6e7d8d14563d1a690a5a8`.

## Исправление проверки рекламных профилей 6 октября 2026

Развёрнута версия `895e43bd0da8c0645b35f8991b4015dea9e09123`. Для `creative.create` с `instagram_user_id` сервис проверяет точный креатив через Meta `validate_only` при подготовке и повторно перед исполнением. Наличие профиля в неполном списке `instagram_accounts` больше не требуется. Отказ Meta, тайм-аут и неверный ответ проверки блокируют операцию.
