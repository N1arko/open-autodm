# Выпуск Instagram Agent API — 28 октября 2026

Установка: https://autodm.niar42.com. Контракт и матрица возможностей:
[INSTAGRAM_AGENT_API.md](../INSTAGRAM_AGENT_API.md).

## Что выпущено

- Чтение профиля, отдельного медиа, детей карусели, tagged media, лимита публикаций,
  подписок и доступности проверки grants.
- Комментарии и ответы с пагинацией; постоянные типизированные операции создания,
  ответа, скрытия/возврата, удаления комментария и включения/выключения комментариев.
- Атомарная зависимость «публикация сейчас/по расписанию → media ID → первый комментарий
  → проверка»; receipts и отдельные статусы. Неопределённые writes остаются `unknown`.
- Одиночное фото, alt text, кадр обложки, AI label; правка caption/времени не начатого задания.
- Приватная загрузка материалов через API, signed URLs, проверка метаданных и библиотека.
- Журнал comments/mentions/live_comments и живое чтение официального Direct inbox;
  чтение сохранённой истории транспорта владельцем.

## Сохранность эксплуатации

До и после выпуска совпали все поля снимка 37 исходных публикаций: ID, владелец,
аккаунт, тип, статус, media ID, время, ключ и request hash. Дополнительно сравнены все первоначальные поля ответа API, включая
caption, исходники и даты: расхождений нет. Ожидают те же 9 заданий.
Настройки привязок ботов и автоматизаций совпали. Активных автоматизаций и bot bindings
в снимке не было; AI-ответы этим выпуском не включались.

Повторный Halloween job `87c65ef0-c44a-4ca9-a290-62b998668d25` сохранил published/media ID.
API прочитал один существующий комментарий под ним. Исторические задания не получали
новых comment operations. Удалённая владельцем исходная публикация не пересоздавалась.

## Доступ и ограничения

Текущий @snippist успешно прошёл чтение комментариев, Direct, профиля, медиа, Stories,
tags и лимита публикаций. Чтение не подтверждает успешный внешний write конкретного типа.

Для этого Instagram Login подключения Meta возвращает code 100 при обращении к
`/me/permissions` и `/{IG_ID}/permissions`: поле отсутствует. Безопасные попытки token
introspection с текущими credentials также не предоставили список. Поэтому
`capabilities.grants=null`, `grants_observed=false`, действия имеют permission-состояние
`unknown`. Требования scopes приведены в контракте; запрошенные OAuth scopes не выданы
за актуальные grants. App Review/Advanced Access по этим ответам не определяется.
Дополнительное OAuth согласие при выпуске не запрашивалось; подписки Meta автоматически
не менялись.

Удаление опубликованного медиа и работа с соавторами требуют отдельного Facebook Login
пути/permissions и в этом выпуске не выполняются. Позиционные user tags и ответы на внешние
mentions остаются следующими типизированными расширениями. Недоступные детали старых
Direct-сообщений остаются явно отсутствующими. Остальные границы перечислены в матрице.

## Восстановление

`/opt/open-autodm-releases/20261028-instagram-agent/` содержит исходники с конфигурацией,
прежний `.release.json`, IDs image, `public-before.dump` и проверенный `pg_restore --list`.
Прежний image отмечен `open-autodm:rollback-20261028-instagram-agent`.

При откате сохраните добавленную схему и сначала разберите новые незавершённые IMAGE/
comment jobs: прежний worker не поддерживает их полностью. Восстановление базы требует
отдельного поручения владельца. Порядок выпуска и отката: [DEPLOYMENT.md](../DEPLOYMENT.md).
