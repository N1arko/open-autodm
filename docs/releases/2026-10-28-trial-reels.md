# Выпуск Trial Reels — 28 октября 2026

На https://autodm.niar42.com выпущена публикация пробных Reels через существующий
`POST /api/v1/publications`. Новый необязательный параметр:

```json
{ "trial_params": { "graduation_strategy": "MANUAL" } }
```

Поддерживаются явные стратегии `MANUAL` и `SS_PERFORMANCE`, расписание, обложка и
зависимый первый комментарий. Прежние задания сохраняют обычный режим. Смена стратегии
с тем же Idempotency-Key возвращает конфликт. Контракт и ограничения:
[PUBLISHING_API.md](../PUBLISHING_API.md#пробные-reels-trial-reels).

## Ограничения и восстановление

Поддержку Trial Reels конкретным аккаунтом окончательно определяет Meta при выполнении.
Живой пробный ролик @snippist для проверки не публиковался. Для MANUAL переход к
обычному Reel выполняет владелец в Instagram; SS_PERFORMANCE передаёт решение Meta.
Сохранённые trial_params описывают запрос создания и не показывают текущую стадию перехода.

Резервные копии конфигурации/исходников, базы public, прежних metadata и image IDs:
`/opt/open-autodm-releases/20261028-trial-reels/`. Dump проверен через pg_restore --list.
Прежний image: `open-autodm:rollback-20261028-trial-reels`.

При откате сохраняйте схему и сначала разберите незавершённые trial jobs: прежний
worker не передаёт trial_params и способен опубликовать их обычными Reels. Восстановление
базы выполняется отдельным поручением владельца. См. [DEPLOYMENT.md](../DEPLOYMENT.md).
